# 🛒 Superstore Sales Analysis

## 📌 Project Overview
Analyzed 9,800+ sales transactions of a US-based superstore 
to identify key business insights using Excel, SQL and Power BI.

## 🛠️ Tools Used
- **Excel** — Data Cleaning & Pivot Tables
- **SQL (SQLite)** — Data Querying & Analysis  
- **Power BI** — Interactive Dashboard

## 📊 Key Insights
- Technology category has the highest sales
- West region leads with 31.4% of total sales
- California is the top performing state
- Sales grew consistently from 2015 to 2018
- Standard Class is the most used shipping mode (5,859 orders)
